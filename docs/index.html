Features

核心设计亮点

🚀

全栈 Bun (1.4+) 驱动

从 Monorepo 依赖管理、TypeScript 编译构建到生产后端托管，全链路 100% 运行于 Bun 原生环境，零 Node.js / Yarn 依赖包袱。

💾

原生 SQLite 高性能持久化

基于 bun:sqlite 并开启 WAL 模式。支持多画板管理、约 30 秒防抖自动同步、Revision 版本冲突防护与画板切出等待确认。

🧼

纯净私有化与零遥测

默认剥离任何第三方跟踪脚本、Google Fonts、Sentry 及官方云端跳转。默认路径仅访问本机或局域网服务，守护数据主权。

⚡

现代浏览器极致性能

面向最新现代浏览器（esnext），去除过时 polyfill 开销。Mermaid 图表、CJK「霞鹜文楷」手绘字体、代码编辑器按需动态加载。

🔐

轻量服务端会话鉴权

支持 AUTH_PASSWORD 密码保护，会话直接记录于 SQLite，凭证通过 HttpOnly Cookie 下发，浏览器端绝不暴露明文凭据。

🐳

极简容器化与 rootless 兼容

基于 Alpine 的极小镜像。单挂载卷 ./data:/app/data 即可持久化数据库与附件，开箱支持 Docker、Podman 与反向代理。

Quick Start

一键部署指南

1. 创建数据目录与配置文件：

mkdir -p ./data

# 创建 docker-compose.yml
services:
  excalidraw:
    build: .
    restart: unless-stopped
    ports:
      - '8080:8080'
    environment:
      - AUTH_PASSWORD=your-strong-password
      - TRUST_PROXY=true
    volumes:
      - ./data:/app/data

2. 启动容器：

docker compose up -d --build

访问：http://localhost:8080 即可畅享私有白板！

前置要求： 安装 Bun (v1.4.0+)

# 1. 安装依赖
bun install

# 2. 编译核心 Packages
bun run build:packages

# 3. 构建前端产物并启动服务 (默认端口 8080)
bun run build
bun run start:server
环境变量 默认值 说明
AUTH_PASSWORD 无 (必填) 访问密码。开启密码保护，生成安全 HttpOnly 会话。
ALLOW_ANONYMOUS false 设为 true 时允许局域网免密匿名直接访问。
TRUST_PROXY false 反向代理或 HTTPS 环境下必须设为 true。
PORT 8080 服务监听端口。
DATA_DIR ./data SQLite 数据库与图片附件存储目录。
