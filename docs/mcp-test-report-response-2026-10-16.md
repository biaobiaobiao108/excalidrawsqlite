# 2026-10-16 MCP 测试报告处理记录

基于测试报告核对当前实现，并使用本地临时 SQLite 和真实 MCP SDK 回归。没有操作报告中的线上端点或画板。报告是问题线索，修复以现有契约和可复现行为为准。

| 报告项 | 处理与判断 |
| --- | --- |
| P0：独立文字溢出静默跳过 | 修复覆盖状态。没有适用容器时返回 `status=not_executed` 和 `complete=false`，部分跳过为 `partial`；摘要明确说明未执行，不再把零问题表达为检查通过。未绑定文字不一定属于附近卡片，因此默认保守；显式开启 `inferTextContainers` 才以文字起点推断唯一实心矩形，多候选不猜。仅寻找完全包含文字的矩形无法发现文字越界，故不采用该推断条件。 |
| P1：全角标点、emoji 偏窄 | 修正全角形式、中日韩宽字符及组合 emoji 的估宽，并用字素簇避免对 ZWJ、肤色和附加符号重复计费。常用模糊宽度标点区分整行中日韩与西文语境。保持 `estimated=true`，不宣称所有字体真实宽度相等或完整实现 Unicode East Asian Width 标准。 |
| P1：input 缺文字高度 | 补充只读 `elementGeometry`，含高度、行高与行数，跟随当前页和字符预算。直接给 `input.elements` 加 `height` 会使严格文字更新报错，也会破坏直接用于创建的既有能力；因此保持 `elements` 可直接写回，将派生值放在旁侧。 |
| P1：业务失败不标 isError | 为客户端兼容性，单次业务失败统一增加 `isError=true`，保留 `ok=false/error.code/message`。聚合批处理仍逐项表达失败。同步更新指引和原有错误契约回归。 |
| P2：诊断摘要不能定位 | 摘要增加类型计数、最多三项问题的严重性、相关图元 ID 和候选位移，以及最大几何重叠深度。不展开全部图元或重复完整 JSON。 |
| P2：小重叠难以分级 | 原本已有面积与比例；新增 `overlapDepth` 和 `severityHint`。实际面积比例阈值为 0.08，不是报告推测的 0.05。保留检测阈值，程度提示仅代表几何，不声称小重叠一定不可见或可以安全忽略。 |
| P2：容器歧义 | 保留保守跳过和既有计数、限制说明，并明确 `partial/not_executed` 状态与摘要。 |
| P2：measure_text 缺行高 | 返回原生倍率 `lineHeight` 和像素行高 `lineHeightPx`；保留现有 `lineCount`，不添加同义字段。行高按实际字体元数据返回，不硬编码为 1.25。 |
| 已验证正常项 | 保留幂等、乐观锁、自动重算、严格参数校验、错误码、批处理、容量截断和分组诊断；新增字段不回写场景，诊断保持只读。 |

回归覆盖：自由文字与绑定标签对照、60×40 矩形上的长文字、默认覆盖不足及显式几何推断、歧义和旋转、未找到容器、轻微/较大重叠分级、标点与组合 emoji、测量与保存尺寸一致、input 直接写回、只读几何分页预算、错误标记以及批处理逐项状态。
